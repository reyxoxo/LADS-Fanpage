This is a fanpage made for Love and Deepspace, called 'Hole in Deepspace, Welcome to Linkon City'!! Not linked with Papergames or Infold ;)
I had so much fun designing a website for what is currently one of my biggest hyperfixations at the moment! I love playing this game, and I thought it would be fun to make a fanpage for it using my newfound coding skills. I made this project with HTML and CSS.
Something I struggled with was definitely formatting, as I only used the center tags in my first website, and this one was a lot more complicated with adding a lot more images and formatting them all to look organized. But overall, I had tons of fun making this project, and hope you like it ;)
